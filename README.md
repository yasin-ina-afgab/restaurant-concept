# فيديو الدعاء — Remotion

فيديو عمودي (1080×1920، 30fps، مدته 61 ثانية) مبني بـ [Remotion](https://www.remotion.dev).

## التشغيل محلياً

```bash
npm install
npm run studio   # معاينة تفاعلية
npm run render   # تصيير final_dua.mp4
```

ملف الصوت `VID_20261122_152316_923.mp3` يجب أن يكون في جذر المستودع؛ يُنسخ تلقائياً إلى `public/audio.mp3` قبل المعاينة أو التصيير. إن لم يوجد يُصيَّر الفيديو بدون صوت مع تنبيه.

## البنية

أسلوب بصري حديث بطابع لوحات التصور البياني: خلفية داكنة، شبكة تقنية دقيقة، زخرفة هندسية دائرية تدور ببطء، وست عقد مترابطة تنتقل بينها الكاميرا مع كل مقطع صوتي.

- `src/scenes.ts`: نصوص المشاهد الست وتوقيتها بالثواني.
- `src/theme.ts`: الألوان والخطوط (Amiri للنص الرئيسي، Readex Pro للنص الفرعي).
- `src/camera.ts`: مواقع العقد وحركة الكاميرا الافتراضية (`spring` على الموضع والتكبير).
- `src/Background.tsx`: التدرج الداكن والشبكة والنجوم والزخرفة الدائرية.
- `src/Nodes.tsx`: المسار والعقد (الذهبي للنشطة، الفيروزي للسابقة).
- `src/SceneText.tsx`: البطاقة الزجاجية فوق العقدة النشطة.
- `src/Hud.tsx`: شريط التقدم السفلي.

## GitHub Actions

`.github/workflows/render.yml` يصيّر الفيديو عند كل دفع (push) ويرفع `final_dua.mp4` في قسم Artifacts باسم `final_dua`.
